# Collections

::: funstruct.collections

Persistent, immutable collection types. All are Functors (support `.map()`),
and most are Semigroups or Monoids (support `+` and have an empty value).

- [Cons](cons.md) — singly-linked list
- [frozendict](frozendict.md) — immutable dictionary
- [Tree](tree.md) — rose tree
